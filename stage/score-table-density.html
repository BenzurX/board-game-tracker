Score Table Density - staging

Problem: Farkle with 4 players overflows a 380px mobile viewport, forcing a horizontal scroll to see everyone's score. Four ideas below, each rendered at real mobile width (380px) with the app's actual dark theme tokens. Sample data: 4 players, 5 rounds of Farkle.

A Current (reference)

Full player names, generous padding. Works great for 2-3 players; at 4 it overflows 380px and requires a right-scroll to see the last player.

D Always-visible leaderboard strip above the table

A horizontally-scrollable row of ranked chips (dot + initial + running total, leader first) sits above the table and never needs a right-scroll to answer "who's winning" - it's a fixed few chips regardless of player count. The detailed round-by-round table underneath can scroll freely for large player counts without losing standings context.

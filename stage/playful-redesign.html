GLOVEBOX-style redesign - 5 stages

Each stage is a shippable stopping point. Stage 1 is a two-hour paint job; Stage 5 is a full identity change. Every stage builds on the one before it, so you can stop wherever the app stops feeling like "your" app. Reference frame first, then Home + Tracker for each stage.

SYSTEMThe Glovebox design system

Palette

Dark plum ink, cream text, six candy accents. The six accents double as the player colors, so the palette and the data colors are the same set - no second system to maintain.

Replaces Commissioner. Baloo 2 keeps a fat rounded terminal at small sizes, which Fredoka's display weights lose. Both are Google Fonts, so the existing single <link> stays a single link.

Sticker buttons

  • Radius: 999px for actions, 20px for cards. Never a small radius.
  • Shadow is a hard offset, no blur: 0 5px 0 rgba(0,0,0,.55).
  • Press = translateY(5px) + shadow to 0. The button physically lands.
  • Optional 3px cream outline promotes a button to "sticker" (used sparingly: invite, FAB, mascot).
  • Tilt (rotate(±1-2deg)) is for decorative tiles only, never for text read in a row.

What carries over

  • The three-theme x two-mode variable structure stays. Glovebox becomes a fourth theme (or replaces Ocean) - same CSS variable blocks, new values.
  • --p0..--p5 player accents remap to the candy six exactly.
  • Light mode = cream paper #F6EFE2 ground, ink text, same candy accents at full saturation. Hard shadows drop to rgba(42,34,51,.22).
  • No markup changes until Stage 3; Stages 1-2 are pure CSS.

STAGE 1Repaint and re-letter

CSS variables and one font link only. Dark plum replaces navy, cream replaces cold blue-white, yellow becomes the primary accent, Baloo 2 + Fredoka replace Commissioner + system sans. Every shape, border and shadow untouched. Ship this alone and the app already reads playful instead of utilitarian.

Cost: ~1 hour. Risk: near zero, fully reversible. Ceiling: still visibly the same layout.

STAGE 2Sticker physics

Shape and shadow rules. Every button becomes a pill with a hard 4-5px drop shadow and presses down into it. Borders deleted in favour of shadow-defined edges; cards go to 20px radius. Uppercase button labels with light tracking. Biggest "feel" change per line of CSS - the app starts responding like a physical toy. Press the buttons in the system panel above to feel it.

Cost: ~half a day. Risk: low. Watch the footer bar keeps enough height for the drop shadow so buttons do not look clipped.

STAGE 3Candy tiles and colour-coded scoring

Colour becomes information. Each game card takes a candy fill cycling through the six accents - the grid reads like the Glovebox pill wall. On the tracker every player owns one accent: their column header is a name pill in their colour, their total is tinted to match. "Who is winning" stops being a numeric comparison and becomes a colour one. Player colour assignment already exists (--p0..--p5), so this is a remap plus a header restyle.

Cost: 1-2 days. Risk: contrast. Yellow and lime need ink text, pink/orange/blue/teal need cream. Bake the pairing into the token, do not decide per use.

STAGE 4Personality: tilt, confetti field, badges

The decorative layer. Cards get a 1-2 degree tilt so the grid looks hand-placed. Loose confetti dots sit behind content. A starburst badge calls out a count ("12 games"). The leader's column wears a crown; the winner banner becomes a sticker ribbon. Nothing here carries meaning not already carried elsewhere, so it all degrades safely.

Cost: 1-2 days. Risk: tilt on interactive rows hurts tap accuracy and readability - keep it on the home grid, never on the score table. Gate motion behind prefers-reduced-motion.

STAGE 5Full identity

The app gets a face. Multicolour per-letter wordmark with rotated glyphs, a mascot tile, an eyebrow line above the logo, a cream capsule tagline at the bottom of home, transparent header with a fat rule, zebra score rows, and a sticker FAB with a cream outline. Themes get renamed to candy variants (Plum / Cream / Neon) rather than Ember / Ocean / Forest. This is where new icons, splash screen and PWA manifest colours change too.

Cost: several days plus new icon art. Risk: this is a rebrand - the app stops looking like the thing your group already knows. Ship as one release, not piecemeal, and snapshot the previous version first.

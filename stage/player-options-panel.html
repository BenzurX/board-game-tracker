Player options panel

One panel for every "tap a player's name" case, solo and multiplayer, with the colour picker folded in so the header dot can go away. Each variant shows the multiplayer host panel (all four powers) at 380px and the solo panel (rename + colour only) at 380px, so the difference between the two is visible side by side. The reference strip at the top is what ships today.

Current (reference)

Today: solo taps the name to get an inline input, and a separate 16px dot opens a colour popover. Multiplayer host gets a bottom sheet with three buttons and no colour control at all. Tradeoff: two entry points, two mental models, and the dot eats header width on every column.

A - One sheet, everything inline

Bottom sheet. Name is a live text input (no second "rename" step), colour is a swatch row right under it, and the host powers sit below a divider as full-width buttons. Tradeoff: tallest of the four, but nothing is hidden behind another tap and the solo version is simply the same sheet with the bottom half removed.

B - Anchored popover

Same content, but it hangs off the tapped chip like today's colour popover instead of taking over the bottom of the screen. Tradeoff: keeps the board visible and feels closest to the current colour dot, but it is cramped at 380px with 6-8 players, and the arrow has to flip for the rightmost column.

380px - solo

C - Sheet with action rows

Header, name input, colour row, then the host powers as flat tappable rows with a glyph, iOS-context-menu style, rather than three stacked pill buttons. Tradeoff: much shorter and it scales if a fifth power is ever added, but the rows read as lighter-weight, so "Remove from game" needs its red to carry the whole warning.

380px - multiplayer host
380px - solo

D - Sheet with an action tile row

Identity and edit fields on top, host powers as a row of square glyph tiles at the bottom, with "Their turn" carrying the accent fill since it is the one used mid-game. Tradeoff: the most compact and the fastest to hit one-handed, but the tile labels have to be two words or fewer, and it does not stretch past three or four actions.

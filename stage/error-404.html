404 screen

Four takes on a not-found screen, all built from the splash's parts: the ambient ground, the shipped mark on its square viewBox, and one Back to Home button using the app's real primary button. The die is tipped and still rather than spinning, since on an error nothing is in progress. Every button here is a real link back to index.html, so it can be clicked from inside the stage page.

E - Hybrid: the die is the 404

A's layout - mark, kicker, line, one button - with B's idea taken all the way: the die is blown up to headline size and carries the whole message, so there are no numerals at all. The centre pip is the only red thing on the screen, and the plate is tipped hard off true. Tradeoff: the calmest and most confident of the set and it scales cleanly to any width, but nothing on screen literally says 404, so the kicker line is doing all the explaining.

F - Hybrid, with the numerals ghosted back in

The same screen as E, with the numerals promoted to full strength: two amber 4s in the display face, tucked in far enough to overlap the plate, reading four - centre pip - four with the pip doing the zero's job. Tradeoff: the only variant that says 404 and uses the mark to say it, but the amber is also the button's colour, so the screen now has two things competing for the eye.

A - Splash echo

The splash screen with the caption swapped for an apology and a button added: same mark, same size, same vertical rhythm. Tradeoff: the cheapest to build and the least jarring if the error lands right after the splash - but it reads as a slow load rather than a dead end, so a user may sit and wait for it to resolve.

B - Die as the zero

A big display-face 404 whose middle character is the die itself, tipped off true. Tradeoff: unmistakably an error page and the most characterful use of the mark - but at 380px the code eats the screen, and the joke only lands if the die is read as standing in for the 0.

C - Carded

The message sits in the same surface card the modals use, over the ambient ground, with a secondary way out under the primary. Tradeoff: the most legible and the most obviously interactive, and the only one with room for a second action - but a card implies something recoverable sits behind it, which on a 404 is not true.

D - Scored as a miss

The error written as a scorecard row: a round called ??? that banked an F, in the board's own zebra rows and Farkle red. Tradeoff: speaks the app's language better than any generic error screen, but it only makes sense to someone who has already used the tracker - a first visit to a bad link gets an in-joke instead of an explanation.
